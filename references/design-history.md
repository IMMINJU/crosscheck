# crosscheck 설계 연혁

실행에는 불필요한 배경 기록. 왜 지금 구조가 됐는지 확인할 때만 읽는다.


(2026-06-26 확정, 2026-07-03 pal 제거, 2026-07-10 gpt-5.6-sol 승격, 2026-07-20 각도분산+UUID resume, 2026-07-23 MAD 연구 반영, 2026-07-30 기각 사유 분류, 2026-08-05 effort 유동 티어)

- **기각 사유 분류 §3-5 신설 (2026-07-30)**: 기존 구조는 **판정에서 끝났다** — 어느 주장이 근거로 확인됐는지는 가리지만, **기각된 쪽이 왜 틀렸는지는 어디에도 안 남는다.** 정답지 없는 판단에서는 결과를 채점할 수 없으므로 **갈라진 지점을 분류하는** 방향으로 메웠다. 5분류(A 근거 오독 / B 경로 미검증 / C 근거 없는 생성 / D 각도 누락 / E 정당한 이견) 중 **B·D 둘이 기존 구조에 대응한다** — B는 §3-4 `[확인:존재]`를 인과로 승격한 사고, D는 §3-1 분해 실패다. **핵심 규율은 "내 R1이 기각됐을 때도 분류한다"** — 심판이 자기 오류를 안 적으면 이 표는 codex 감점표가 되고, 철칙 3(내가 심판이자 당사자)이 무너진다. 침투 지점 3곳: §3-4 출력 템플릿에 표 1개 추가 / 종료 기준에 1항 추가 / §4 무변경.

  **같은 날 자기적용 교차검증으로 4곳 교정 (2026-07-30)**: 신설 직후 이 스킬을 §3-5 자신에게 적용했다(codex + 각도 3개 + 메인). 4진영이 독립적으로 같은 3대 결함을 짚었다. ① **"조정할 게 없으면 그건 E다"를 삭제** — 오류 원인이 아니라 **조치 가능성으로 분류를 역결정**하는 순환논법이었고, E의 정의를 둘로 갈라(판단 대립 vs 잔여) 규율 2를 문서 스스로 무력화했다. **고칠 수 없는 오류일수록 E로 세탁되는데 그게 대개 더 구조적인 결함이다.** 조정은 `필요/불필요/보류`로 분리. ② **우선순위 사슬 C→A→B→D→E 명시** — 212행이 "유형을 하나 붙인다"고 강제하면서 다중 해당 시 규칙이 없었다. C/D 선택이 신뢰 강등 발동을 좌우해 심판이 자기 오류를 D로 몰 통로가 됐다. ③ **"C가 반복되면 신뢰 강등"을 판 내부로 한정** — 판 간 누적을 금지해놓고 판 간 반복을 전제한 죽은 규칙이었다. 집행을 시도하면 근거를 자기 인상에서 조달해 철칙 2(블라인드)를 깬다. ④ **제목을 "다음 판에 남긴다"→"기각을 원인으로 분류한다"로 수정하고, 판 간 전달 매체가 사람임을 명시** — 에이전트는 판을 넘어 기억하지 못한다. 자동 개선 루프가 아니라 사용자에게 넘기는 자리다. 부수 확인: 각도 하나가 "표 열 정렬이 깨졌다"고 보고했으나 파이프 개수 실측(전 행 4열 일치)으로 기각 — **다수결이 아니라 근거 재검증이 작동한 실증**(철칙 3). 그리고 자기적용 표에서 우선순위 부재 결함이 첫 실행에 바로 재현됐다. **미결**: 미포괄 유형(인과 비약·시점 불일치·범위 이탈 등)을 추가할지는 보류 — 5분류를 9분류로 늘리면 첫 실행부터 분류가 부담이 된다. 몇 판 돌려 실제 걸리는 것만 넣는다.

- **MAD(multi-agent debate) 부정 연구 반영 (2026-07-23)**: "모델 경쟁이 오답률을 높인다"는 주장을 Claude 웹조사 + codex 독립조사로 교차검증(이 스킬을 스킬 자신에게 적용). 결론: 실패하는 건 **합의 강제 + 반복 토론 + 근거 검증 없는 주장 대결** 구조(Wynn 2509.05396: 정답→오답 전환이 역방향보다 잦음, 혼합구성 MMLU −12%p / Choi NeurIPS 2025: MAD 이득의 본체는 토론이 아니라 초기 독립 응답, 토론 추가 시 이득 소멸 / Zhang 2502.08788: MAD가 CoT·self-consistency 못 이김, 유일한 일관 개선책=모델 이질성 / Khan ICML 2024: 검증 가능한 근거+강한 판정자일 때만 토론이 작동, judge 48%→76%). 기존 구조(블라인드 R1·다수결 배제·근거 재검증·2라운드 상한·모델 이질성)는 이미 안전지대. 이번 개정 5개: ① 철칙 5 "합의는 증거가 아니다"(에러 상관: Kim 2506.07962 같은 오답 60% 일치, Kohli 2605.29800 9-judge 유효표 2.18) ② R2 익명 증거 패킷(진영명·합의 수 제거 — Conformity 2410.12428) ③ 인과 라벨 3단계(존재/경로/인과 — 파일:라인은 존재 검증이지 인과 검증이 아님, codex 발견) ④ R1→R2 전환 감사표(원답 보존) ⑤ R2 조건부 발동. 부수 확인: Claude 조사와 codex 조사의 맹점이 정확히 갈렸음(Claude=에러 상관 축, codex=검증 사다리 축) — 이 스킬의 존재 이유 실증.

- **각도 분산 구조 + UUID resume (2026-07-20 실측)**: 라운드1을 "codex 전체질문 1세션(모델 축) + Claude 각도 서브에이전트 병렬(각도 축)"로 확장. 근거: 같은 모델에 같은 질문을 중복시키면 오류가 상관돼 무가치하고, 이득은 각도 분해에서 나온다(Anthropic 멀티에이전트 리서치 시스템 — 막연한 지시로 서브에이전트 2개가 중복 조사한 실패사례, "각 서브에이전트에 목표·출력형식·경계 필요", 90.2% 우위의 메커니즘 = "서로 다른 측면의 병렬 탐색"). R2는 `codex exec resume <uuid>`로 전환 — 병렬 세션 중 비최신 세션 UUID 타겟팅·모델 자동 상속·기존 allowlist 커버·rollout 파일명 폴백 전부 실측 확인. 부수 관찰: codex 2개 병렬 시 모델캐시 갱신 경합 ERROR 로그가 뜰 수 있으나 exit 0이면 무해. 파생 효과: `--last` 의존이 사라져 **여러 Claude Code 세션의 동시 crosscheck이 안전**해졌다(산출물은 원래부터 세션 스크래치패드 격리).
- **reasoning effort 유동 티어 (2026-08-05 실측)**: "더 좋은 모델 나왔나" 확인에서 시작 — `models_cache.json`(2026-08-05 fetch, codex-cli 0.144.1) 기준 `gpt-5.6-sol`이 여전히 priority 1 "Latest frontier agentic coding model"이고 5.7·6은 없다. 대신 **effort가 그동안 `none`이었다는 걸 발견**했다. 배너가 직접 찍어준다. `default_reasoning_level: low` 필드는 대화형 피커용이라 `codex exec`엔 적용되지 않는다 — 이 필드만 보고 "low로 돌 것"이라 추정한 게 1차 오독이었고 배너 실측으로 교정했다(철칙 3: 근거를 직접 열어야 한다). 잘못된 값(`=bogus`)은 조용히 무시되지 않고 400 나므로 플래그가 API까지 가는 건 확실하다.

  **4점 실측** — 같은 프롬프트(crosscheck.md 읽고 "절차에 남은 가장 심각한 결함" 찾기, 근거 인용 요구):

  | effort | 시간 | 토큰 | 짚은 결함 |
  |---|---|---|---|
  | `none` | 25.9초 | 25.9k | 공유 증거 — read-only라 반증 실험 금지 (외부 제약) |
  | `medium` | 28.6초 | 28.0k | 공유 **전제** — 블라인드는 답 베끼기는 막지만 프레이밍 오류 상관은 못 막는다 |
  | `high` | 39.2초 | 41.0k | 프레이밍·증거 완전성 검증 부재 |
  | `xhigh` | 31.7초 | 37.4k | 같은 결함, 근거 인용이 가장 정밀(철칙 3 행 + §3-1 각도분해 + R2 패킷 선별 + §3-4 종합) |

  **가장 큰 도약은 `none`→`medium`** (+2.7초, +2.1k로 거의 공짜). none은 외부 제약을 짚었고 medium부터 구조적 결함을 짚는다. **`high`는 채택하지 않았다** — xhigh가 같은 결함을 더 정확한 근거로 짚으면서 오히려 빠르고 쌌다(단조 증가가 아니다). 그래서 medium 기본 + 고위험만 xhigh의 2단 구조. **effort는 resume에 상속되지 않아** R2에 다시 명시해야 한다(모델은 상속되는데 effort만 `none`으로 떨어짐) — R2가 반박 라운드인데 추론이 꺼져 있던 셈이다. 한계: 티어당 1회, 프롬프트 1종(문서 독해형)뿐이라 xhigh<high 역전은 노이즈일 수 있고 코드 인과 추적형에서는 순서가 다를 수 있다. 몇 판 돌려 교정한다. 부수 확인: medium·high·xhigh 셋이 **같은 결함(메인이 프레이밍·각도·패킷·심판을 독점)에 수렴** — 철칙 5대로 수렴 자체는 증거가 아니지만, effort를 올려 얻은 건 다른 결함 발견이 아니라 같은 결함의 더 정밀한 정위였다. 이 지적 자체는 미결로 남긴다(3-5 기각분류 §미결과 같은 축).

- **모델 gpt-5.6-sol 채택 (2026-07-10 실측)**: 5.6부터 티어제(sol 프런티어 / terra 저비용 / luna 고속)로 바뀌었고, `sol`은 코드네임이 아니라 정식 모델명의 일부다. **접미사 없는 `gpt-5.6`은 ChatGPT 구독 인증에서 400 차단**(`not supported when using Codex with a ChatGPT account`)이라 "sol 뗀 5.6"을 기다리는 건 무의미 — `gpt-5.6-sol`이 구독으로 쓸 수 있는 프런티어 티어다. codex-cli **0.144+ 필요**(0.142는 `requires a newer version` 400). R1에 `-m gpt-5.6-sol`만 붙이면 R2 resume은 세션에서 모델을 **자동 상속**한다.
- **pal:clink 제거 (2026-07-03 실측)**: clink는 codex CLI를 셸로 띄우는 래퍼일 뿐이다. 직접 호출로 바꾸면 ① 의존성 1개 제거 ② `-s read-only`가 **OS 레벨 샌드박스**로 강제됨(Windows 실측: 쓰기 시도 → UnauthorizedAccessException 차단, 파일 미생성. clink는 `--dangerously-bypass`로 띄우고 프롬프트로만 부탁하는 구조였다) ③ `exec resume`이 continuation_id를 완전 대체.
- **gemini**: 2026-06-18부로 무료 OAuth 차단(`UNSUPPORTED_CLIENT`). 헤드리스 자동화 불가 → **제외**.
- **claude 외부호출 폐기 유지**: clink claude든 `claude -p`든 결국 **메인 나와 같은 모델**을 시간·한도 써가며 한 번 더 부르는 것. 독립 관점 가치가 없다. → 그 자리는 메인 나의 직접 조사 + 각도 분해다.
- **3번째 엔진(로컬 모델)? — 저사양 노트북에선 비추천 (2026-06-26 실측)**: 전용 GPU 없는 노트북(통합그래픽 + RAM 16GB급)에선 3~8B급만 가능(30B MoE는 RAM 초과). CPU 추론이라 초당 몇 토큰 → 콜이 수십초~분, 속도 이점 없음. 3~8B는 gpt-5.6-sol/opus 대비 추론력 격차 커 난제 교차검증의 "강한 눈" 역할 불가. **2모델 체제(codex × 메인나)가 이 하드웨어의 최적해.** 로컬 추가는 GPU 워크스테이션 생기면 재검토.
- 결과: codex(진짜 외부 엔진) + 각도 서브에이전트(질문 분해) + 나(직접 검증) = **독립성 2축 + 의존성 최소 + 진짜 샌드박스**.
